1. Main features and intended purpose

No Land allows users to access and control a rented, GPU-enabled Linux computer from their iPhone.

Its primary use case is remote PC gaming, but the app is not limited to games. The remote computer provides a complete desktop environment that can also be used for other desktop-computing or GPU-intensive tasks.

The app's main features are:

- Finding GPU-powered computers available through Vast.ai.
- Allowing users to select and rent a computer using their own Vast.ai account.
- Automatically configuring the rented Linux computer for remote access.
- Establishing a secure WireGuard connection between the iPhone and the remote computer.
- Streaming the remote computer's desktop, video, and audio to the iPhone.
- Sending the user's input from the iPhone to the remote computer.
- Allowing users to reconnect, pause, reboot, or terminate their rented computer.

No Land provides access to computing infrastructure. It does not sell, license, or provide games.

2. Intended target audience

No Land is intended for iPhone users who want access to a GPU-enabled computer but do not own suitable computer hardware.

This includes:

- People who cannot afford or do not want to purchase a gaming computer.
- Users who only occasionally require access to powerful GPU hardware.
- PC gamers who want to access their personally owned game libraries from an iPhone.
- Users who prefer a pay-as-you-go alternative to purchasing and maintaining their own computer hardware.

Users are responsible for obtaining any games or other software they use, including all required purchases, accounts, subscriptions, and licenses.

3. How No Land works

No Land operates as follows:

1. The user connects their Vast.ai account

The user supplies credentials for their own Vast.ai account. No Land uses the Vast.ai API to display available GPU computers, including their prices, locations, storage, GPU specifications, and availability.

2. The user selects a computer

The user selects a machine based on factors such as its GPU, price, location, storage, and availability. The rental is associated with the user's Vast.ai account.

3. No Land configures the remote computer

After the computer becomes available, No Land connects to it and automatically configures the components required for remote access. This includes the Linux graphical environment, NVIDIA GPU configuration, Sunshine streaming host, audio services, and WireGuard networking.

4. A secure connection is established

No Land creates an encrypted WireGuard tunnel between the user's iPhone and that specific remote computer.

5. The remote desktop is streamed to the iPhone

The remote computer performs the actual processing and rendering. Video and audio are streamed to the iPhone, while the user's input is transmitted back to the remote computer.

6. The user supplies their own games and software

No Land does not include a game library. Users may sign in to services such as Steam on their remote computer and install games they already own, subject to the relevant platform and publisher licensing terms.

For example, a user may rent a GPU computer, connect to its Linux desktop, sign in to their own Steam account, install a game from their own library, and stream the computer's display to their iPhone. No Land supplies the remote-computing and streaming functionality, not the game.

4. Relationship with Vast.ai

Vast.ai is the third-party infrastructure marketplace currently used by No Land to locate and provision GPU computers.

No Land is an independent application. It is not owned, sponsored, endorsed by, or formally partnered with Vast.ai. We do not have a separate written partnership or custom commercial agreement with Vast.ai.

The app uses Vast.ai's publicly available services and API under its standard terms and requirements. Users access Vast.ai through their own accounts and are responsible for the computing resources rented through those accounts.

No Land acts as a client and orchestration interface. It helps users select, configure, and connect to a computer that they rent through Vast.ai.

Relevant public information is available at:

- Vast.ai: https://vast.ai/
- Vast.ai documentation: https://docs.vast.ai/

5. Use of NEVPNManager

No Land uses NEVPNManager and NETunnelProviderManager to create and manage a WireGuard packet tunnel between the user's iPhone and their selected remote computer.

The tunnel provides a stable and encrypted private connection for:

- Remote desktop video and audio streaming.
- Transmission of the user's input.
- Pairing and connection management.
- Connection health checks.
- Management of the user's rented computer.

The tunnel is limited to traffic required to communicate with the No Land remote computer. It is not a general-purpose VPN service.

No Land does not use the tunnel to:

- Route or inspect the user's unrelated internet traffic.
- Circumvent geographic restrictions.
- Monitor traffic from other applications.
- Provide anonymous internet browsing.

The user initiates the connection when connecting to their remote computer, and the iPhone presents the standard system VPN permission prompt. No Land manages the tunnel's installation, connection, reconnection, status, and removal.

The WireGuard configuration is stored securely using the iPhone Keychain rather than as unprotected application data.

The implementation of the iPhone app, its Network Extension, and the WireGuard tunnel management code can be reviewed in our public source-code repository:

https://github.com/FelipeBarrosCode/no_land_mobile_port

6. Guideline 4.7.4 - Index of non-embedded games or software

No Land does not provide a remotely hosted game or software catalog. Therefore, there are currently no games distributed, licensed, or made available by No Land that can be included in such an index.

Any applications or games displayed in the app's launch interface are discovered from software that the individual user has installed on their own rented computer. This list is different for every user and functions similarly to the application list on a remote desktop.

No Land does not select, host, sell, license, or unlock those titles.

Users must:

- Obtain their games and applications independently.
- Own or otherwise have permission to use them.
- Sign in using their own third-party accounts.
- Install them on the computer they rent and control.
- Comply with the applicable developer, publisher, and platform terms.

The following webpage is only a compatibility-search resource based on public Steam and ProtonDB information:

https://no-land.net/games/

It helps users determine whether a title may run on a remote Linux computer. It is not a catalog of games supplied or made available by No Land. A title appearing on this webpage does not provide the user with access to that title.
